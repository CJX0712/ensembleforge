# Model Card — EnsembleFuse

> 作者：晨星 (CJX0712)

## 模型概要
- **名称**：EnsembleFuse（Caruana Bagged Ensemble Selection）
- **类型**：自动化集成选择（元算法），非独立预测模型
- **输入**：基模型库的交叉验证 OOF 概率 + 训练标签
- **输出**：按权重组合的集成概率（等权平均，权重 ∝ 被选中频次）

## 预期用途
- 在多样化基模型库上自动选出稳健集成，降低单模型选择风险。
- 适用于分类概率融合、模型库压缩、鲁棒性提升。

## 训练数据
- 合成多类 DGP（blobs / moons / circles / xor），含标签噪声，固定 seed 可复现。
- 不依赖任何外部数据集或预训练权重（完全离线）。

## 评估指标
- 主指标：测试集 **log-loss**（越低越好）。
- 次指标：accuracy / macro-F1。
- 对照：最强单模型（按 OOF log-loss 选）、朴素等权平均集成、各基模型。

## 性能门槛（DoD，诚实框定）
- G1：EnsembleFuse 聚合测试 log-loss **非劣于（≈）最强单模型**（差异落入噪声区间，不显著更差）。
  - 理论依据：候选集含单模型本身 ⇒ 集成在选型准则上至少不弱于最佳单模型；
    集成取平均后，测试 log-loss 一般落在「最佳单模型」与「平均单模型」之间，故以「非劣」为门槛，禁止虚报「严格更优」。
- G2：EnsembleFuse 聚合测试 accuracy **非劣于** 最强单模型（margin ≤ 0.5pp）。
- G3：EnsembleFuse 聚合测试 log-loss **显著低于** 朴素平均集成（证明「选型 > 朴素袋装」——真实可证胜点）。
- 统计显著性：采用 ≥3 seed 多折聚合，判据为均值差 > ½(σ₁+σ₂)（SOP 约定）。

## 限制
- 性能取决于基模型库的多样性；库内全弱则集成也弱。
- 选型以 log-loss 为准则；若任务以 accuracy 为先，可改准则（接口预留）。
- 合成基准用于方法验证，真实分布迁移需重新校准。
